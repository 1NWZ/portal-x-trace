# Seedance 无 API 视频工作流

本技能负责理解照片、设计 TRACE 动态效果和组织提示词，不自带视频模型。无需 API 密钥或接入点。没有可用模型工具或网页访问时，交付提示词与操作说明，不能声称已经生成视频。

## 根据输入编写完整提示词

先观察照片中的主体、姿态、光线、背景和构图；只写有依据的细节。默认一个短镜头，避免为静态照片强行设计大幅转身、遮挡或复杂动作。用户要求主体静止时，让动态仅发生在扫描线、追踪框和叠加层。

可用下面的结构组织提示词，交付前替换所有括号内容：

> 以所上传照片为首帧，保留[主体身份、外观、服装或物件结构]及[原始环境与构图]。主体[明确、克制的动作，或按用户要求保持静止]。镜头[固定或缓慢推进等单一运动]。加入 PORTAL-X TRACE 的[选定风格]：追踪框稳定贴合主体轮廓，细线连接少量目标点，[主题色]扫描线缓慢移动，坐标和短标签克制呈现，轻微胶片颗粒与短暂局部故障效果。保持主体清晰，画面连续，叠加层运动有节奏且不遮挡面部。避免五官漂移、肢体变形、追踪框乱跳、杂乱长文字、强烈闪烁和突然切镜。

四种风格：Evidence Tree 为档案标签和证据连线；Red Machine 为红色警报块和追踪框；Biotech Grid 为科学网格和交点；Surveillance 为监控编号和目标标记。每次选择一种主风格。

需要精确文案或严格定位的标签时，说明生成模型可能无法可靠复现；用户需要精确控制才使用本地工具制作参考首帧。不要把录制该网页当作 Seedance 视频。

## 无模型访问时的交付

1. 明确标注：视频生成提示词（尚未生成视频）。
2. 给出一段完成填充、可直接粘贴的提示词。
3. 建议使用原图比例、平台支持的短时长和一个克制镜头；具体可选模型、比例、时长以用户当前界面为准。
4. 提示用户在已有的即梦或其他 Seedance 可用界面上传原图、选择图生视频、粘贴提示词并生成。不要声称已经检查用户账号权限。

用户只说“修改技能”时只修改技能，不要求上传照片或实际生成。用户要求生成且已有工具访问时执行生成，不仅交付模板。
